                                                                                                                                                                                      2. 寵物孵化：透過「寵物蛋」孵化。寵物蛋可從任務獎勵、副本掉落、商城購買或活動獲取。
                                                                                                                                                                                        • 技巧：高級寵物蛋有機會孵化出稀有甚至史詩級寵物。利用「孵化加速器」可縮短等待時間。
                                                                                                                                                                                      3. 活動獎勵：遊戲會不定期舉辦各類活動，提供限定寵物或稀有寵物蛋作為獎勵。
                                                                                                                                                                                        • 技巧：密切關注官方公告，積極參與活動，這是獲取特殊寵物的重要途徑。
                                                                                                                                                                                      4. 交易行/玩家交易：在遊戲內交易行或與其他玩家直接交易，可購買到心儀的寵物。
                                                                                                                                                                                        • 技巧：了解市場行情，避免高價購入資質不佳的寵物。出售高資質閒置寵物也是不錯的賺錢方式。

                                                                                                                                                                                      1. 等級提升與經驗獲取

                                                                                                                                                                                      • 戰鬥獲取：攜帶寵物參與戰鬥，寵物會獲得經驗值。

                                                                                                                                                                                      • 技巧：初期可將主力寵物與新寵物一同組隊，讓新寵物「蹭」經驗快速成長。

                                                                                                                                                                                      2. 技能學習與搭配

                                                                                                                                                                                      寵物技能分為天生技能、學習技能和專屬技能。

                                                                                                                                                                                      • 天生技能：寵物出生即帶有，通常與其種族特性相關。
                                                                                                                                                                                      • 學習技能：透過「技能書」學習，可替換或新增技能。
                                                                                                                                                                                        • 技巧：根據寵物定位選擇合適的技能書。例如，輸出寵學習增傷技能，輔助寵學習治療或控制技能。注意技能格數量，合理規劃。
                                                                                                                                                                                      • 專屬技能：部分稀有或傳說寵物擁有獨特的專屬技能，效果強大。
                                                                                                                                                                                        • 技巧：專屬技能是衡量寵物潛力的重要指標之一，善用其特效能扭轉戰局。

                                                                                                                                                                                      3. 潛力與資質培養

                                                                                                                                                                                      • 潛力點分配：寵物每升一級會獲得潛力點，可手動分配到生命、魔力、力量、防禦、敏捷等屬性。
                                                                                                                                                                                        • 技巧：根據寵物定位進行「專精」分配。例如，物理輸出寵主加力量，肉盾寵主加生命與防禦。
                                                                                                                                                                                      • 資質洗練：使用「資質洗練石」可重置寵物的成長資質。資質越高，寵物每級獲得的屬性成長越高。
                                                                                                                                                                                        • 技巧：這是決定寵物最終強度的關鍵環節。務必將主力寵物的核心資質洗練至接近滿值。

                                                                                                                                                                                      4. 進化與突破

                                                                                                                                                                                      • 進化：部分寵物達到特定等級或條件後可進行進化，外形與能力會發生質變。
                                                                                                                                                                                        • 技巧：進化通常需要消耗特定材料，建議提前收集。進化後的寵物會解鎖更強大的技能或屬性。
                                                                                                                                                                                      • 突破：消耗同名寵物或通用突破材料，提升寵物的星級或階級，大幅提升基礎屬性與技能效果。
                                                                                                                                                                                        • 技巧：突破是後期提升戰力的主要手段之一，但消耗巨大。優先突破核心主力寵物。
